# Private Winter Sale, Neve Atelier

A one-page landing page for the private winter sale of a luxury womenswear brand.
Neve Atelier is a fictional brand, made for a design test.

Live page: https://miny320.github.io/private-winter-sale/

## What is on the page

- Hero with a campaign photo, headline, two calls to action and a live countdown.
- "The edit": six products with private price, original price, discount and sizes.
- Client services: delivery, returns, private styling and gift wrapping.
- Call to action: a form to request a private access code, with validation and a thank-you state.
- On phones, a sticky bar keeps the main button in reach.

## How it is built

- Plain HTML, CSS and JavaScript. No framework and no build step.
- Fonts from Google Fonts (Cormorant Garamond and Jost).
- Photos resized and saved as WebP.
- Accessible: skip link, labelled form fields, visible focus, and reduced motion support.
- The form has no back end. A real shop would send the email to its newsletter or customer platform.
